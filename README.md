# Jalurtumbuh Jobs - Frontend (Next.js + TypeScript + Tailwind CSS)

## Cara Menjalankan
1. Pastikan server Backend sudah berjalan di `http://localhost:4000`.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Jalankan server development:
   ```bash
   npm run dev
   ```
4. Akses portal:
   - Portal Utama & Pencarian Lowongan: `http://localhost:3000`
   - Login / Register Kandidat & Perusahaan: `http://localhost:3000/login`
   - Portal Admin (Login + CRUD Perusahaan & Kandidat): `http://localhost:3000/admin`
   - Portal Super Admin (Login + Manajemen User & Sistem): `http://localhost:3000/superadmin`
